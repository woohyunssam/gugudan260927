# 차근차근 구구단

초등학교 2학년을 위한 8단계 구구단 학습 웹 앱입니다.

## 학습 단계

1. 같은 수씩 묶기
2. 그림을 식으로 바꾸기
3. 한 묶음씩 늘리기
4. 배열을 돌려 짝꿍 식 찾기
5. 아는 답으로 새 답 찾기
6. 가리고 떠올린 뒤 확인하기
7. 내가 만드는 구구단 문제
8. 구구단 섞어 풀기

## 실행

별도의 패키지 설치나 빌드 없이 실행하는 HTML/CSS/JavaScript 앱입니다.

```sh
python -m http.server 8765 --directory dist
```

브라우저에서 http://localhost:8765 를 엽니다. 정적 웹 호스팅에는 `dist` 폴더를 게시합니다.

## 학습 기록

배운 범위, 5~7단계 카드, 8단계 날짜별 기록은 브라우저의 localStorage에 저장합니다. 다른 기기나 브라우저와 자동 동기화되지 않으며, 브라우저 데이터를 삭제하면 기록도 사라집니다. 실제 학습자 기록은 이 저장소에 포함되지 않습니다.

## 파일

- `dist/index.html`: 화면 구조와 스타일
- `dist/app.js`: 홈과 1단계
- `dist/stage2.js` ~ `dist/stage8.js`: 단계별 활동
- `dist/storage.js`: 기기 내 학습 기록 저장과 복원
